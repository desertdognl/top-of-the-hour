Draaiboek-modus

Flex: unlocked cues schuiven mee bij in-/uitlopen. Locked ankers (slotje) blijven op planningstijd. Dit is iets anders dan de rode Test-offset. Snelle toggle ook in de topbar.

Tijd bepaalt hoe ver het wiel vooruit kijkt. Aantal items dimt cues verder dan N in de timeline.

Schermonderdelen

Wiel

Links blijft klein; rechts loopt de grootte op naar NOW.

Secondentimer

Cue-alert

Sneltoetsen: D klaar · S snooze · A volgend anker · F regie

Regie

Alleen wiel + now; ankers blijven als gele dots. Lijst verdwijnt ook als chrome zichtbaar is.

Wall-clock ankers

Vastgezette cues (slotje in de timeline) blijven op planningstijd. Bij een nieuwe import worden ze herkend (via t− / titel) en opnieuw gelockt met de nieuwe tijd.

Export

Exporteer het geladen draaiboek als genormaliseerde cues.

Webinterface

Browser-view via IP + poort (read-only). Zelfde layout als de app: seconden + wiel + timeline.
